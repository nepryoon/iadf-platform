# iadf-release

Corsia privilegiata isolata (§13.1): merge, trusted build, firma, deploy e rollback con identità distinte a vita breve per operazione; ingresso dagli agent negato; fail closed e serializzato per target (§15.1, §17.3).

Deployable isolato del baseline IADF: privilegio e failure isolation ne giustificano l'esistenza (ADD §15.2). I ruoli agent sono configurazioni, non servizi.
